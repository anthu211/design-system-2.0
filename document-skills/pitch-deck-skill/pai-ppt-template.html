Hard Rules (SKILL.md Reference)

Mandatory Slide Rules
✓ Slide 1 = 4_Custom Layout, NO text, NO shapes
✓ Slide 2 = 11_ or 3_Custom Layout (dark purple bg MANDATORY)
✓ Last slide = 4_Custom Layout, NO text, NO shapes
✓ Every interior slide MUST have idx=4 slide number
✓ Slide number format: <  [n] at bottom-right corner
✓ Max 5 bullets · Max 10 words per bullet · Max 1 sub-level
Code Rules
✓ Always load Template_PAI_Presentation (2).pptx
✓ Call prepare_template(prs) immediately after load
✓ Use insert_slide_at(prs, i, layout) for every interior slide
✓ Skip idx=4 when setting text (auto field)
✓ Set text via run.text = ... not placeholder.text = ...
✓ Font: Calibri / Calibri Light only · Never web DS colors

Slide Build Order
1. Cover — 4_Custom Layout (already in template, don't recreate)
2. Title/Agenda heading — 11_ or 3_Custom Layout, dark purple
3–N. Interior slides — any content layout
N+1. Back Cover — 4_Custom Layout (already in template, don't recreate)

prepare_template() strips slides 2–7, keeps slide 1 (cover) and slide 8 (back cover). Insert all content between them using insert_slide_at(prs, i, layout) where i starts at 1.
